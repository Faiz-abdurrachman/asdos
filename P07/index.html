Bahasa Universal API

Format JSON & 3 Aturan Emas Penulisan

JavaScript Object Notation — format teks ringan standar global yang dipahami semua bahasa pemrograman.

payload_menu.json 
{
  "status": "success",
  "total": 2,
  "data": [
    {
      "id": 1,
      "nama": "Nasi Goreng Spesial",
      "harga": 15000,
      "tersedia": true
    },
    {
      "id": 2,
      "nama": "Es Teh Manis Jumbo",
      "harga": 5000,
      "tersedia": true
    }
  ]
}
JSON adalah teks murni. Python membaca JSON menjadi Dictionary & List.
3 Aturan Emas JSON (Anti Galat):
1
Wajib Petik Ganda ("..."): Kunci (keys) dan teks string wajib petik dua. Petik satu ('...') akan memicu JSONDecodeError.
2
Tipe Data Kaya: Number tanpa petik, boolean huruf kecil (true/false), array [...], dan object {...}.
3
Anti Trailing Comma: Jangan beri koma setelah item terakhir dalam list atau object.
Semantik Protokol HTTP

4 Kata Kerja HTTP (CRUD) & Status Code

Bahasa isyarat standar antara Client dan Server dalam arsitektur RESTful web services.

PEMETAAN 4 KATA KERJA HTTP
GET Membaca data menu (Read)
POST Menambah menu baru (Create)
PUT Memperbarui menu yang ada (Update)
DELETE Menghapus menu dari daftar (Delete)
KODE STATUS SEMANTIK SERVER
200 OK Permintaan berhasil diproses.
201 Created Data menu baru berhasil dibuat di server.
400 Bad Request Format JSON salah atau nama menu kosong.
404 Not Found ID menu yang dicari tidak ada di database.

# ✅ SUDAH TERSEDIA DI STARTER KIT (Baris 10 - 50)
# Periksa file app.py kamu untuk memahami struktur data ini:
menu_kantin = [
    {"id": 1, "nama": "Nasi Goreng Spesial", "harga": 15000, "kategori": "Makanan", "stok": 20},
    {"id": 2, "nama": "Mie Ayam Bakso", "harga": 13000, "kategori": "Makanan", "stok": 15},
    {"id": 3, "nama": "Es Teh Manis Jumbo", "harga": 5000, "kategori": "Minuman", "stok": 50}
]

def cari_menu_by_id(item_id):
    """Mencari dictionary menu berdasarkan ID (Prinsip DRY)"""
    for item in menu_kantin:
        if item["id"] == item_id:
            return item
    return None

Langkah 03 app.py • Endpoint POST Menu Baru

Menangkap JSON Body & Validasi Server-Side

Menangkap data dengan request.get_json(), auto-generate ID unik, dan kembalikan status 201 Created.

app.py PASTE DI BAWAH KOMENTAR LANGKAH 2 (BARIS 74) 
# Sisipkan tepat di bawah: # TULIS KODE LANGKAH 2 (POST MENU) DI SINI
@app.route('/api/menu', methods=['POST'])
def tambah_menu():
    data = request.get_json()
    if not data:
        return jsonify({"status": "error", "pesan": "Body JSON wajib ada!"}), 400

    nama = data.get('nama', '').strip()
    harga = data.get('harga')
    kategori = data.get('kategori', 'Makanan')
    stok = data.get('stok', 0)

    # Validasi field
    if not nama or not isinstance(harga, (int, float)) or harga <= 0:
        return jsonify({"status": "error", "pesan": "Nama wajib diisi & harga > 0!"}), 400

    # Auto-generate ID unik (ID tertinggi + 1)
    new_id = max([i['id'] for i in menu_kantin], default=0) + 1
    menu_baru = {"id": new_id, "nama": nama, "harga": int(harga), "kategori": kategori, "stok": int(stok)}
    menu_kantin.append(menu_baru)

    return jsonify({"status": "success", "pesan": "Menu berhasil ditambahkan!", "data": menu_baru}), 201
Status 201 Created adalah standar REST untuk entitas baru yang berhasil disimpan.

The Testing Barrier

Mengapa Kita Butuh Postman untuk Menguji API?

Keterbatasan address bar browser dan alasan penting penggunaan API Testing Tool di industri.

BATASAN BROWSER BIASA

Address Bar Hanya Bisa Melakukan GET

Ketika kamu mengetikkan URL di Chrome atau Edge, browser secara mutlak selalu mengirim request dengan kata kerja GET.

Browser tidak punya tombol untuk memilih method POST, tidak bisa memasukkan header JSON, dan tidak bisa mengetikkan Request Body!
SOLUSI STANDAR INDUSTRI

Postman & Thunder Client: Penguji API

Alat penguji API memungkinkan kita menyimulasikan segala skenario komunikasi (POST/PUT/DELETE) sebelum frontend selesai dibuat.

Bisa memilih method POST/PUT/DELETE, mengatur header Content-Type, mengirim payload raw JSON, dan memeriksa status code balasan server.
💡 Tips Praktis: Belum punya Postman? Pasang ekstensi Thunder Client di VS Code (1-klik, ringan, dan langsung pakai tanpa bikin akun!).

# Sisipkan tepat di bawah: # TULIS KODE LANGKAH 3 (PUT & DELETE) DI SINI
@app.route('/api/menu/<int:item_id>', methods=['PUT'])
def update_menu(item_id):
    item = cari_menu_by_id(item_id)
    if not item:
        return jsonify({"status": "error", "pesan": "Menu tidak ditemukan!"}), 404

    data = request.get_json() or {}
    if 'nama' in data: item['nama'] = data['nama']
    if 'harga' in data and data['harga'] > 0: item['harga'] = int(data['harga'])
    if 'stok' in data: item['stok'] = int(data['stok'])

    return jsonify({"status": "success", "pesan": "Menu diperbarui!", "data": item}), 200

# 5. Hapus Menu (DELETE)
@app.route('/api/menu/<int:item_id>', methods=['DELETE'])
def hapus_menu(item_id):
    item = cari_menu_by_id(item_id)
    if not item:
        return jsonify({"status": "error", "pesan": "Menu tidak ditemukan!"}), 404

    menu_kantin.remove(item)
    return jsonify({"status": "success", "pesan": f"Menu '{item['nama']}' dihapus!"}), 200

Langkah 07 Smart Feature • Endpoint Cuaca Kampus

Rekomendasi Menu Berdasarkan Cuaca Real-Time

Endpoint /api/cuaca-kampus memetakan suhu cuaca ke rekomendasi hidangan kantin.

app.py PASTE DI BAWAH KOMENTAR LANGKAH 4 (BARIS 90) 
# Sisipkan tepat di bawah: # TULIS KODE LANGKAH 4 (EXTERNAL WEATHER API) DI SINI
@app.route('/api/cuaca-kampus', methods=['GET'])
def get_cuaca_kampus():
    url = "https://api.open-meteo.com/v1/forecast?latitude=-7.8014&longitude=110.3647&current_weather=true&timezone=Asia%2FBangkok"
    try:
        res = requests.get(url, timeout=5)
        res.raise_for_status()
        current = res.json().get('current_weather', {})
        suhu = current.get('temperature', 28.0)

        # Logika bisnis rekomendasi menu
        if suhu >= 30.0:
            saran = "Cuaca terik! Rekomendasi: Es Teh Manis Jumbo!"
        elif suhu <= 25.0:
            saran = "Cuaca sejuk/hujan! Rekomendasi: Mie Ayam Bakso Kuah!"
        else:
            saran = "Cuaca nyaman! Semua menu kantin siap dinikmati."

        return jsonify({"status": "success", "suhu_celcius": suhu, "rekomendasi_menu": saran}), 200
    except requests.RequestException:
        # Graceful fallback jika internet lab offline
        return jsonify({"status": "fallback", "suhu_celcius": 28.5, "rekomendasi_menu": "Es Teh Manis Jumbo selalu aman!"}), 200
Blok try-except melindungi backend dari kegagalan koneksi jika jaringan lab offline.
Verifikasi: Buka http://127.0.0.1:5000/api/cuaca-kampus → Suhu real-time & saran menu muncul!

Langkah 08 Frontend Fetch • Asynchronous JavaScript

Frontend Asynchronous: JavaScript `fetch()`

Mengambil dan mengirim data di latar belakang tanpa reload halaman menggunakan async / await.

templates/index.html SUDAH AKTIF DI TEMPLATE • BEDAH KODE FETCH 
// ✅ SUDAH AKTIF DI TEMPLATE: templates/index.html (Mewarisi base.html)
// 1. Memanggil GET dengan fetch (Asinkron)
async function muatMenu() {
    const res = await fetch('/api/menu');
    const json = await res.json();
    console.log(json.data); // Array data menu kantin
}

// 2. Mengirim POST dengan fetch (Body JSON)
async function kirimMenu(menuBaru) {
    const res = await fetch('/api/menu', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json' // Wajib untuk JSON!
        },
        body: JSON.stringify(menuBaru)
    });
    const hasil = await res.json();
    alert(hasil.pesan);
}
Info Praktikum: Kode ini sudah terpasang rapi di template index.html. Buka filenya untuk membedah cara kerjanya!

Freshmen Shield

Antisipasi 6 Eror Terpopuler Pemula & Solusi

Katalog galat yang paling sering dialami mahasiswa semester 3 saat belajar API.

request.get_json() return None Eror 1
Lupa menyertakan Content-Type application/json di Postman/fetch.
Postman: Tab Body → raw → JSON. Di fetch: tambah headers.
ModuleNotFoundError: 'requests' Eror 2
Menjalankan server di luar virtual environment aktif.
Pastikan ada tanda (.venv), lalu jalankan: pip install requests.
405 Method Not Allowed Eror 3
Rute Flask hanya mengizinkan GET, tetapi ditembak dengan POST/DELETE.
Cek decorator rute: methods=['GET', 'POST', 'PUT', 'DELETE'].
JSONDecodeError: Double Quotes Eror 4
Menulis string JSON dengan petik satu ('...') atau ada trailing comma.
Ganti semua petik satu ke petik dua ("...") dan hapus koma akhir.
