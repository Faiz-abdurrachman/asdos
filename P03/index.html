Dasar teori · 1 dari 4

HTML: kerangka halaman web

HTML itu bahasa markup penanda struktur. Klik tiap elemen untuk tahu perannya.

<html>

Root element — pembungkus seluruh isi halaman. Semua elemen lain berada di dalamnya.

Dasar teori · 2 dari 4

CSS: memberi gaya pada struktur

CSS bekerja dengan pola selector lalu property : value. Klik tiap aturan untuk membacanya.

body { ... }

Gaya dasar untuk seluruh halaman: jenis huruf, jarak baris, warna latar, dan warna teks.

Dasar teori · 3 dari 4

Tiga cara memasang CSS

CSS bisa ditempel langsung, ditulis di dalam HTML, atau dipisah ke file sendiri. Yang terakhir paling rapi.

Inline

Ditulis di atribut style="..." sebuah elemen. Cepat, tapi cepat berantakan kalau banyak.

tidak disarankan

Internal

Ditulis di dalam <style> pada <head>. Hanya berlaku untuk satu halaman itu.

cukup untuk 1 halaman

Eksternal

Dipisah ke style.css lalu disambung via <link>. Satu file untuk semua halaman.

yang kita pakai

Kenapa eksternal? Kamu ubah satu tempat, seluruh halaman ikut berubah — dan kode HTML tetap bersih.

Dasar teori · 4 dari 4

Kerangka yang sama di tiap halaman

Tiga bagian ini muncul di semua halaman. Isi main yang berubah; header dan footer tetap.

1

<header> + <nav>

Judul dan menu navigasi ke tiap halaman.

2

<main> + <section>

Konten utama — bagian yang berbeda di setiap halaman.

3

<footer>

Catatan bawah, misalnya copyright.

kerangka HTML
<body>
  <header>
    <h1>Judul</h1>
    <nav> <a href="/">Home</a> ... </nav>
  </header>

Praktikum · Part 1 — perhatikan navigasi

Menu yang menghubungkan halaman

Tiga link di dalam <nav> menuju tiga route berbeda. href="/about" artinya “buka alamat /about”.

potongan <header>
<header>
  <h1>Selamat Datang di Web Saya</h1>
  <nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
    <a href="/contact">Contact</a>
  </nav>
</header>

href = tujuan

Atribut href menentukan halaman mana yang dibuka saat link diklik. Teks di antara <a>...</a> adalah yang terlihat.

Nanti route /about dan /contact kita daftarkan di app.py, jadi link ini benar-benar berpindah halaman.

navigasi = 20% nilai
Praktikum · Part 1 — penghubung

Sambungkan style.css ke HTML

Satu baris di dalam <head> sudah cukup. Tekan tombolnya untuk melihat hasil akhirnya di browser.

di dalam <head>
<link rel="stylesheet"
  href="{{ url_for('static',
    filename='css/style.css') }}">
templates/index.html
<link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">

url_for('static', ...) adalah sintak Jinja. Flask menerjemahkannya menjadi jalur asli ke folder static/.
