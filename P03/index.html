Dasar teori · 2 dari 4

Design Tokens: Kendali warna di :root

CSS custom properties membuat tema mudah diatur. Ubah satu variabel, seluruh portofolio berganti.

:root { ... }

Pseudo-class tertinggi untuk mendeklarasikan token desain: --bg, --accent, --gold, dan --glass.

Dasar teori · 3 dari 4

Kapan Flexbox, kapan CSS Grid?

Keduanya bekerja sama di dalam portofoliomu. Tidak ada yang lebih baik; gunakan sesuai kebutuhan.

Flexbox (1 Dimensi)

Mengatur elemen dalam satu arah (baris atau kolom). Sangat ideal untuk:

  • Menu navigasi di <header> (sejajar menyamping)
  • Susunan foto profil + teks bio di Hero section
  • Baris tombol aksi dan tag pill
display: flex

CSS Grid (2 Dimensi)

Mengatur elemen dalam baris dan kolom sekaligus. Sangat ideal untuk:

  • Galeri kartu proyek di projects.html
  • Daftar artikel blog di blog.html
  • Kotak statistik angka di about.html
display: grid
Dasar teori · 4 dari 4

Jinja2: Memuat file statis dengan aman

Flask memakai template engine Jinja2. Kurung kurawal {{ ... }} mencetak output dinamis.

di dalam file HTML
<!-- 1. Memuat file CSS -->
<link rel="stylesheet"
  href="{{ url_for('static', filename='css/style.css') }}">

<!-- 2. Memuat foto profil -->
<img src="{{ url_for('static', filename='images/profile.jpg') }}"
  alt="Foto Profil">

Mengapa pakai url_for?

Jangan menulis path langsung seperti /static/.... Fungsi url_for('static', ...) otomatis menghasilkan URL absolut yang valid di sistem operasi mana pun.

Bahkan jika port atau subfolder web berganti, link file statismu tidak akan pernah rusak.

bebas link patah

Praktikum · Part 2 — styling

Pondasi style.css: Reset & Tokens

Setelah kerangka HTML dan foto profil siap, kita pasang seluruh styling CSS-nya.

static/css/style.css
*, *::before, *::after {
  margin: 0; padding: 0;
  box-sizing: border-box;
}

:root {
  --bg: #0A0A0C;
  --text: #F4F4F6;
  --text-soft: #B9B9C6;
  --text-muted: #7C7C8A;
  --accent: #9BA8FF;
  --accent-2: #CDB8FF;
  --gold: #C9A86A;
  --glass: rgba(255, 255, 255, 0.045);
  --r-xl: 26px;
  --r-lg: 20px;
  --r-pill: 999px;
}

Arsitektur CSS Siap Pakai

Tombol salin style.css lengkap di atas menyalin seluruh styling (Reset, Animasi View Transitions, Typewriter, Glassmorphism, hingga Responsive Mobile).

  • Semua warna dikontrol oleh token di :root
  • Menggunakan unit fleksibel rem & View Transitions API
  • Layout kartu responsif otomatis tanpa Bootstrap/Tailwind
