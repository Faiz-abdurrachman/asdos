Masalah Nyata

Kenapa Butuh Dynamic Routing?

Bayangkan jika website portofolio Anda nantinya memiliki 100 catatan blog atau artikel teknis:

❌ Cara Statis (Tanpa Dynamic Route)

Anda harus membuat 100 fungsi route berbeda di app.py dan 100 file HTML manual:

@app.route('/blog/artikel-1')
def blog1():
    return render_template('blog1.html')

@app.route('/blog/artikel-2')
def blog2():
    return render_template('blog2.html')
# ... diulang sampai 100 kali! 😱

✅ Cara Cerdas (Variable Rules)

Cukup 1 Rute Dinamis di Flask untuk melayani jutaan artikel sekaligus:

@app.route('/blog/<int:post_id>')
def blog_detail(post_id):
    # post_id ditangkap dari URL
    artikel = cari_artikel(post_id)
    return render_template(
        'blog_detail.html',
        artikel=artikel
    )
Teori Dasar

Variable Rules & Converter Types

Flask menyediakan pengonversi bawaan untuk memastikan URL yang diketik pengunjung valid sesuai tipe datanya:

Converter Contoh Sintaks Keterangan
string (default) /user/<nama> Menerima teks apapun tanpa tanda slash /
int /blog/<int:id> Hanya menerima bilangan bulat positif (angka 0-9)
float /rate/<float:val> Menerima angka desimal dengan titik
path /files/<path:p> Menerima teks yang mengandung tanda slash /

Langkah 1 • Backend

Setup Import Baru & Secret Key

Buka app.py. Kita butuh fungsi baru dari Flask dan memasang secret_key agar fitur flash message berjalan:

Kenapa Butuh Secret Key?

Flash Message disimpan dalam Session Cookie di browser. Secret key digunakan oleh Flask sebagai tanda tangan kriptografi (signing) agar isi cookie tidak bisa dimanipulasi dari luar.

app.py 
from flask import Flask, render_template, request, redirect, url_for, flash

app = Flask(__name__)
# Wajib untuk flash messages
app.secret_key = 'kunci-rahasia-portofolio-faiz'

Membuat Rute Dinamis di app.py

Dua Jenis Rute Dinamis

Perhatikan bagaimana parameter dalam kurung sudut <...> otomatis menjadi argumen fungsi Python:

app.py 
@app.route('/blog/<int:post_id>')
def blog_detail(post_id):
    artikel = next((item for item in data_blog if item["id"] == post_id), None)
    return render_template('blog_detail.html', aktif='blog', artikel=artikel, post_id=post_id)

@app.route('/user/<nama>')

Langkah 3 • Frontend

Menghubungkan Halaman Blog ke Rute Dinamis

Bagaimana menghubungkan daftar artikel di templates/blog.html dengan rute /blog/<int:post_id> yang baru kita buat di app.py?

🔗 Jembatan: url_for() dengan Parameter

Jangan tulis URL manual! Flask menyediakan fungsi cerdas url_for() untuk mengisi parameter URL otomatis:

RUMUS URL DINAMIS FLASK:
url_for('nama_fungsi', nama_param=nilai)
👉 'blog_detail' = nama fungsi di app.py
👉 post_id=item.id = disuntikkan ke <int:post_id>
👉 Hasil Nyata = /blog/1, /blog/2, dst.
Keunggulan DRY: Jika rute di app.py diubah dari /blog/ jadi /artikel/, seluruh link di website otomatis update tanpa edit HTML manual!

templates/blog.html

Pasang url_for() di atribut href link "Baca Selengkapnya":

templates/blog.html 
{% for item in artikel_list %}
<div class="blog-card">
    <span class="date">{{ item.tanggal }}</span>
    <h3>{{ item.judul }}</h3>
    <p>{{ item.ringkasan }}</p>
    <span class="badge">{{ item.kategori }}</span>

    <!-- LINK DINAMIS: post_id diisi dari item.id -->
    <a href="{{ url_for('blog_detail', post_id=item.id) }}">
        Baca Selengkapnya &rarr;
    </a>
</div>
{% endfor %}

Teori HTTP

HTTP Methods: GET vs POST

Dua metode komunikasi paling penting antara browser dan server web:

HTTP GET • "Kartu Pos Terbuka"

Digunakan untuk mengambil data. Parameter ditempel langsung di URL browser:

  • Terlihat di address bar: /search?keyword=flask
  • Dapat disimpan di Bookmark peramban
  • Ada batasan panjang URL (~2048 karakter)
  • DILARANG untuk data sensitif seperti password

HTTP POST • "Surat Amplop Tertutup"

Digunakan untuk mengirim data baru. Data dibungkus di dalam Request Body:

  • Tidak tampil di URL address bar browser
  • Tidak dapat dibookmark sembarangan
  • Ukuran data praktis tidak terbatas (cocok untuk pesan/file)
  • WAJIB untuk formulir login, kontak, atau upload

Langkah 6 • Backend

Backend Handler & Pola PRG

Tangani kiriman data form di app.py dengan method POST dan terapkan pola Post/Redirect/Get:

Kenapa Wajib Redirect Setelah POST?

Jika me-render template langsung dari POST, saat user menekan refresh (F5), browser akan memunculkan popup *"Confirm Form Resubmission"*. Pola PRG mencegahnya!

app.py 
@app.route('/contact', methods=['GET', 'POST'])
def contact():
    if request.method == 'POST':
        nama = request.form.get('name')
        email = request.form.get('email')
        pesan = request.form.get('message')
        
        flash(f'Terima kasih, {nama}! Pesan berhasil dikirim.', 'success')
        # Pola PRG: Selalu redirect setelah POST!
        return redirect(url_for('contact'))
        
    return render_template('contact.html', aktif='contact')

Langkah 7 • Global Alert

Wadah Flash Messages di base.html

Letakkan blok get_flashed_messages() di layout induk templates/base.html agar alert otomatis aktif di semua halaman:

Satu Tempat untuk Semua Notifikasi

Dengan menaruhnya di dalam tag <main> di base.html, Anda tidak perlu mengulang kode alert di halaman lain:

templates/base.html 
{% with messages = get_flashed_messages(with_categories=true) %}
  {% if messages %}
    <div class="flash-container">
      {% for category, message in messages %}
        <div class="flash-alert flash-{{ category }}">
          <span class="flash-text">{{ message }}</span>
        </div>
      {% endfor %}
    </div>
  {% endif %}
{% endwith %}

Latihan Modul Perkuliahan

Formulir Login Sederhana (/login)

Implementasi tugas resmi modul: autentikasi kredensial simulasi menggunakan Flash Danger dan Flash Success:

Logika Backend /login

Jika kredensial admin / 12345 cocok, kirim flash sukses; jika salah, kirim flash danger merah:

app.py 
@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        u = request.form.get('username')
        p = request.form.get('password')
        if u == 'admin' and p == '12345':
            flash('Login berhasil! Selamat datang, Admin.', 'success')
            return redirect(url_for('home'))
        flash('Username atau password salah!', 'danger')
    return render_template('login.html', aktif='login')
