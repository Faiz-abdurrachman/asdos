Solusi Jinja2

Solusi: Prinsip "Kop Surat" (DRY)

DRY = Don't Repeat Yourself. Jangan mendesain logo dan kop surat berulang-ulang di setiap surat. Buat satu master, lalu isi kontennya!

1. base.html (Kop Surat)

Menampung <head>, link CSS, navbar, dan footer. Menyediakan slot lubang {% block content %}.

2. 6 Halaman Anak

Cukup panggil {% extends 'base.html' %} dan hanya menuliskan isi konten utamanya saja.

3. Efisien & Mudah

Mau ubah menu navbar atau copyright footer? Cukup edit 1 file saja (base.html) dan 6 halaman otomatis terupdate!

Anatomi Induk

3 Zona Penting di base.html

Pahami peran masing-masing baris kode yang baru saja kalian salin:

1. {% block title %}

Memberi judul default tab browser. Jika halaman anak tidak mendefinisikan judul, otomatis memakai Home.

2. {% block content %}

Ini adalah lubang dinamis utama. Apapun yang ditulis di halaman anak akan disuntikkan ke dalam tag <main> ini.

3. Menu Aktif Cerdas

{% if aktif == 'about' %} class="active"{% endif %} membuat link menu menyala terang sesuai halaman yang lagi dibuka.

Masalah Data Hardcode

Kenapa Data Tidak Boleh Diketik Mati di HTML?

Di P-03, nama, umur, dan keahlian diketik manual di file HTML. Bayangkan kalau data kalian berasal dari database!

Cara Lama (Statis / Kaku)

Data diketik langsung di file HTML.
• Kalau ganti semester, harus cari barisnya di HTML.
• Kalau nambah keahlian, harus copy-paste tag div manual.
• Tidak bisa dihubungkan ke database SQL!

Cara Baru Jinja2 (Dinamis / Bersih)

Data dikelola penuh di file Python app.py.
• Disimpan dalam bentuk Dictionary dan List.
• Dikirim ke template lewat fungsi render_template().
• Siap diintegrasikan dengan database MySQL/SQLite!

from flask import Flask, render_template app = Flask(__name__) # Data Mahasiswa (Dictionary untuk Variabel Tunggal) profil = { "nama": "Faiz", "umur": 20, "kota": "Malang", "kampus": "Universitas Brawijaya", "semester": 3 } # Daftar Keahlian (List of Dict untuk Loop & Kondisi) skills = [ {"nama": "HTML & CSS", "level": 90}, {"nama": "Flask", "level": 85}, {"nama": "JavaScript", "level": 75}, {"nama": "Python", "level": 70} ] @app.route("/") def home(): return render_template("index.html", aktif="home", profil=profil) @app.route("/about") def about(): return render_template("about.html", aktif="about", profil=profil) @app.route("/skills") def keahlian(): return render_template("skills.html", aktif="skills", skills=skills) @app.route("/projects") def projects(): return render_template("projects.html", aktif="projects") @app.route("/blog") def blog(): return render_template("blog.html", aktif="blog") @app.route("/contact") def contact(): return render_template("contact.html", aktif="contact") if __name__ == "__main__": app.run(debug=True)

Konsep Inti: Halaman projects, blog, dan contact tetap statis di HTML-nya. Kita hanya memindahkan data yang butuh diuji konsepnya (profil & skills)!

Pertolongan Pertama

Mengalami Error? Cek 4 Hal Ini Dulu!

Jangan panik kalau terminal merah atau browser error. 99% masalah mahasiswa pemula ada di sini:

1. TemplateNotFound

Penyebab: File base.html dibuat di luar folder.
Solusi: Pastikan semua file HTML disimpan di dalam folder templates/.

2. Unexpected end of template

Penyebab: Lupa tag penutup blok.
Solusi: Cek pasangan tag: ada block harus ada {% endblock %}, ada for harus ada {% endfor %}.

3. Halaman Putih Kosong

Penyebab: Typo nama blok di file anak.
Solusi: Pastikan namanya persis sama: {% block content %}, bukan block isi.

4. BuildError for endpoint

Penyebab: Typo di helper url_for().
Solusi: Nama di dalam url_for('home') harus sesuai dengan nama fungsi di app.py (misal: def home():).
